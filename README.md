# TS팀 도구 앱 (홈 화면 앱)

기술영업팀 업무용 도구 모음. 핸드폰 홈 화면에 추가해서 앱처럼 쓰고, 인터넷이 없어도 열립니다.
도구 4개(Raw Data 정리 도구 · Spot Calibration · Control 계산기 · 검사지침서 생성기)가 **한 화면의 탭**으로 들어 있습니다.

## 폴더 구성
- `index.html` 통합 도구 (= `TS팀_도구.html`에 앱 설정을 더한 것, 약 4.6MB). 도구 4개가 모두 이 파일 안에 들어 있음
- `manifest.webmanifest` · `sw.js` · `icons/` 앱 설치 · 오프라인 설정 (`sw.js`는 업데이트할 때 버전 숫자만 올림)
- `robots.txt` 검색 사이트에 안 나오게 하는 설정
- `README.md` 이 안내 (지워도 앱에는 영향 없음)
- 예전 `tools` 폴더(도구 파일 4개)는 더 쓰지 않음 → 저장소에서 지워도 됨

## 1. GitHub Pages에 올리기 (처음 한 번)
1. github.com에서 새 저장소 만들기: 오른쪽 위 `+` → New repository
   - 이름: 원하는 이름 (이름이 주소에 들어감)
   - **Public** 선택 (무료 계정은 Public만 Pages 사용 가능)
   - "Add a README file"은 체크하지 않기
2. 만든 저장소 화면에서 **uploading an existing file** 클릭
3. 이 폴더 안의 내용물(`index.html`, `sw.js`, `manifest.webmanifest`, `robots.txt`, `icons` 폴더, `README.md`)을 한꺼번에 끌어다 놓기
   - 폴더째 올리면 안 됨: `index.html`이 저장소 맨 위에 있어야 함
   - `icons` 폴더도 함께 끌어다 놓으면 폴더 구조가 유지됨
4. 아래 **Commit changes** 클릭
5. 저장소 **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
6. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/저장소이름/` 이 나옴 → 이 주소가 앱 주소
   - 주소가 열리면 위쪽에 탭 4개(Raw Data · Spot Cal · Control · 지침서)가 보여야 정상. 처음에는 Raw Data가 열리고, 다음부터는 마지막에 쓴 탭이 열림

주의: Public 저장소라 저장소 주소를 아는 사람은 계산기 파일(컨트롤 데이터 포함)을 볼 수 있음. 검색 사이트에는 나오지 않게 해 두었지만, 주소는 팀 안에서만 공유하기. 회사 정책상 곤란하면 올리기 전에 확인.

## 2. 핸드폰에 설치
- 안드로이드(Chrome): 주소 열기 → 오른쪽 위 ⋮ → "홈 화면에 추가" 또는 "앱 설치"
- 아이폰(Safari): 주소 열기 → 아래 공유 버튼 → "홈 화면에 추가" (Chrome 앱이 아니라 Safari에서)
- 한 번 열어 두면 인터넷이 없어도 열림.

## 3. 도구를 고쳤을 때 (업데이트)
1. 새 도구가 나오면 통합 도구(`TS팀_도구.html`)도 새로 만들어지므로, 앱용 `index.html`을 새로 받음
2. `sw.js`를 열어 맨 위 `ts-tools-v5`의 숫자를 하나 올림 (v5 → v6). 새로 받은 `sw.js`에 이미 올라가 있으면 그대로 사용
3. GitHub 저장소에서 **Add file → Upload files**로 `index.html`과 `sw.js`를 올려 덮어쓰기 → Commit
4. 1~2분 뒤 반영됨. 핸드폰은 인터넷이 될 때 앱을 열면 새 파일로 바뀜. 안 바뀌면 앱을 완전히 닫았다가 다시 열기(GitHub는 파일을 몇 분간 보관해서 바로는 안 바뀔 수 있음)
5. 되돌리고 싶으면 저장소의 History에서 이전 버전을 받아 다시 올리면 됨

## 문제가 생겼을 때
- 주소가 404: Settings → Pages에서 Branch가 `main` / `(root)`인지, `index.html`이 저장소 맨 위에 있는지 확인
- 앱이 열리는데 아이콘이 깨져 보임: `icons` 폴더가 저장소에 올라갔는지 확인 (폴더 구조가 유지되지 않고 파일이 맨 위에 흩어져 올라가는 경우가 많음)
- 엑셀 보고서 · Word 다운로드가 안 됨(특히 아이폰 홈 화면 앱): 같은 주소를 Safari 브라우저 탭에서 열어 다운로드
- 검사지침서 생성기 · Raw Data 정리 도구는 PC 화면 기준으로 만든 도구라 핸드폰에서는 보기 · 확인용으로 쓰고, 작성은 PC 브라우저에서 같은 주소로 하는 것을 권장
- 앱을 이전 버전(메뉴 화면이 있던 판)에서 바꾼 뒤에도 예전 화면이 보이면: 앱을 완전히 닫고 다시 열기. 그래도 같으면 브라우저 설정에서 이 사이트 데이터를 지우고 다시 열기
